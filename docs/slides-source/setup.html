How you use it

Load your statement

sync

The agent sorts every row

review

You settle what was held back

chat

Ask about your spending

The goal: give it a bank statement as a CSV, get categorized books, then talk to the agent about your spending. The agent runs on claude -p with a small set of tools. A code gate, not the model, decides what is booked automatically. Anything large or doubtful waits for a person. The ledger is Akaunting, or a local stand-in so it runs anywhere. The four commands at the bottom are the whole workflow.
